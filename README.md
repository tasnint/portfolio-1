# Tanisha's Portfolio

My personal portfolio website: a sky-themed walk through my story, experiences, projects and skills.

Built with React, TypeScript and Vite, from my own Figma designs.

## What's inside

- **My story:** drag the star along the bar to flip through photos and captions, with floating clouds.
- **My experiences:** a card for each role, with twinkling sparkles.
- **My projects:** pulled live from GitHub, with falling rain.
- **My skills:** category clouds with skills raining down from them.
- **Sign-off:** how to reach me (and a reminder to go touch some grass).

## Running it locally

Requires Node 22 (see `.nvmrc`).

```bash
nvm use
npm install
npm run dev
```

| What | File |
